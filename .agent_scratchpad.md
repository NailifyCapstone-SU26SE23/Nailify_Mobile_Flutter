## Progress / Completed Steps
- Identified root cause of deposit QR issue:
  - `POST /api/Wallets/deposit` returned only `string` (CheckoutUrl).
  - Mobile app received only the HTTP URL string, so scanning raw URL as QR code failed in banking apps.
- Designed In-App VietQR Deposit Solution:
  1. Update Backend C# `RequestDepositAsync` in `IWalletService.cs`, `WalletServices.cs`, `WalletsController.cs` to return `PaymentResponseDto` (contains `QrCode` VietQR string, `CheckoutUrl`, `OrderCode`, `Amount`).
  2. Update Mobile Flutter `WalletApiService`, `WalletRepository`, `DepositSheet`, and `WalletOverviewPage` to receive `PaymentResponseDto` map and navigate to `PaymentQrPage` (or display VietQR QR image directly in-app).
- Created detailed `implementation_plan.md` artifact containing full code changes for review.

## Key Decisions Made
